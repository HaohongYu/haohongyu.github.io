# Haohong Yu · Academic Homepage

[Visit the live site](https://haohongyu.github.io/).

## Edit the site

1. Open [index.html on GitHub](https://github.com/HaohongYu/haohongyu.github.io/blob/main/index.html) while signed in as `HaohongYu`, and select the pencil icon.
2. Find the section to update by its ID: `about`, `research`, `teaching`, or `cv`. Edit the HTML and select **Commit changes**. For a research project, keep the date and status with the description. When a manuscript, DOI, or project repository is public, add its link to the corresponding project.
3. Check [Actions](https://github.com/HaohongYu/haohongyu.github.io/actions) for the Pages deployment, then open the live site to confirm the changes.

## Publish a research file

1. Sign in as `HaohongYu` and open [Upload on GitHub](https://github.com/HaohongYu/haohongyu.github.io/upload/main/research/outputs).
2. Choose a public-facing file such as a paper PDF, a ZIP archive, or a dataset. Give it a descriptive filename. Select **Commit changes** to add it to `research/outputs/` on `main`.
3. After the [Pages deployment](https://github.com/HaohongYu/haohongyu.github.io/actions) finishes, check [Research Outputs](https://haohongyu.github.io/#research-outputs). The site lists uploaded files automatically, using each filename as its title.

This repository and its upload folder are public. The GitHub browser uploader accepts files up to 25 MiB each.

GitHub Pages builds the site with Jekyll from the `main` branch and repository root.
