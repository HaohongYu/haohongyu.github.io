# Haohong Yu · Academic Homepage

[Visit the live site](https://haohongyu.github.io/).

## Edit the site

1. Open [index.html on GitHub](https://github.com/HaohongYu/haohongyu.github.io/blob/main/index.html) while signed in as `HaohongYu`, and select the pencil icon.
2. Find the section to update by its ID: `about`, `research`, `teaching`, or `cv`. Edit the HTML and select **Commit changes**. For a research project, keep the date and status with the description. When a manuscript, DOI, or project repository is public, add its link to the corresponding project.
3. Check [Actions](https://github.com/HaohongYu/haohongyu.github.io/actions) for the Pages deployment, then open the live site to confirm the changes.

For a local preview, open `index.html` in a browser. GitHub Pages publishes the `main` branch from the repository root. The site has no build dependencies.
